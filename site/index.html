An open file format for stitched-craft patterns.

PTRN builds on the Craft Yarn Council standards the community already uses, so a pattern can travel as structured data instead of a flat PDF. No company owns it, and anyone can use it.

Why a shared format

Today a pattern is a document a person reads. PTRN describes every stitch, where it goes and how rows relate, so any app can chart it, check the counts, track a maker's place and switch between US and UK terms, from the same file.

One file, any app

A designer publishes once. Any conforming reader can open it, now and later.

The vocabulary makers know

Uses the CYC abbreviations and chart symbols instead of inventing new ones.

Offline, forever

Everything a pattern needs is inside the file. No network, no account, no vendor.

Free to implement

An open spec, JSON Schemas and test files. No permission or fees required.

For craft organizations and guilds

Built on your standards, not around them

The Craft Yarn Council's abbreviations and chart symbols are the foundation of PTRN's stitch vocabulary. We want the people who set and teach those standards to shape the format before it's final.

Crafts in scope

Crochet and knitting come first, because both are covered by the CYC standards. Cross-stitch, needlepoint and embroidery are reserved in the format and come later.

Get in touch

Organizations, designers and developers can write to the Working Group directly. Proposed changes to the format go through public issues on the spec repository.

hello@ptrnformat.org Open an issue

Governance. Decisions are made in public and recorded with their reasoning. The long-term intent is to move PTRN to a neutral foundation, with community input on that move.

Versioning. Breaking changes only in a new major version. Minor versions only add optional fields.
